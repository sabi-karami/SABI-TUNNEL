## SABI TUNNEL برای ویندوز ۳.۱.۰

**تازه‌ها**
- نام برنامه SABI TUNNEL شد. روی نسخه‌ی قبلی (TrustTunnel) نصب می‌شود و سرورها و تنظیمات سر جایشان می‌مانند.
- سرورهای پیش‌فرض از پنل: خودکار اضافه، به‌روز و حذف می‌شوند. سرورهای خودتان دست نمی‌خورند. سرور پیش‌فرضِ پاک‌شده در همگام‌سازی بعدی برمی‌گردد.
- به‌روزرسانی خودکار و بی‌صدا: نسخه‌ی تازه در پس‌زمینه دانلود و بررسی می‌شود و وقتی وصل نیستید (یا مدتی با سیستم کار نکرده‌اید) نصب می‌شود و دوباره وصل می‌شود.

**دانلود**
- `SabiTunnel-Setup.exe`: نصب‌کننده (پیشنهادی).
- `SabiTunnel-Windows.zip`: نسخه‌ی بدون نصب؛ `SabiTunnel.exe` را اجرا کنید.
- `SHA256SUMS.txt`: هش فایل‌ها.

اگر SmartScreen هشدار داد، More info و بعد Run anyway را بزنید.
