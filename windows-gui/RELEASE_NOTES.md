## TrustTunnel برای ویندوز ۳.۰.۱ · «شب فیروزه»

نسخه‌ی اصلاحی برای لینک‌های سرویس‌دهنده‌های دیگر، به‌خصوص لینک‌هایی که به‌جای IP نشانی دامنه‌ای (رله) دارند. طراحی تازه‌ی نسخه‌ی ۳.۰.۰ همه سر جایش است.

**اصلاح‌ها**
- نشانی دامنه‌ای سرور پیش از اتصال پیدا می‌شود: اول با DNS ویندوز، و اگر جواب نداد یا جواب فیلترشده (10.10.34.x) داد، با DNS امن (DNS-over-HTTPS) کلادفلر، گوگل و AdGuard. نام دامنه در سرور ذخیره‌شده دست نمی‌خورد.
- پینگ این سرورها هم نمایش داده می‌شود.
- لینکی که از تلگرام یا متن فارسی کپی شود و نویسه‌های نامرئی جهت‌نما داشته باشد، یا وسط یک پیام باشد، درست خوانده می‌شود.
- اگر لینک ناقص کپی شده باشد یا برای نسخه‌ی جدیدتر TrustTunnel ساخته شده باشد، پیام روشن فارسی نشان داده می‌شود.
- اگر اتصال برقرار نشود، علت واقعی نشان داده می‌شود (مثلاً «نشانی دامنه‌ی سرور پیدا نشد»)، نه فقط «اتصال به‌طور غیرمنتظره بسته شد».

**دانلود**
- `TrustTunnel-Setup.exe`: نصب‌کننده (پیشنهادی). روی نسخه‌ی قبلی نصب می‌شود و سرورها، تنظیمات و فهرست سایت‌های مستقیم شما سر جایشان می‌مانند.
- `TrustTunnel-Windows-GUI.zip`: نسخه‌ی بدون نصب. پوشه را باز کنید و `TrustTunnel.exe` را اجرا کنید.
- `SHA256SUMS.txt`: هش فایل‌ها برای بررسی سلامت دانلود.

اگر SmartScreen هشدار داد، روی More info و بعد Run anyway بزنید. دلیلش این است که برنامه امضای دیجیتال پولی ندارد. فایل‌ها در همین ساخت با Microsoft Defender اسکن شده‌اند و پاک‌اند.
